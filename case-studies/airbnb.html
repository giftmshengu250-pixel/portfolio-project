Project Overview

This capstone project brought together frontend and backend development in the creation of an Airbnb-inspired accommodation platform. The focus was on creating a functional experience where users could browse available listings, explore property details, and interact with a booking-oriented interface that felt clear and intuitive.

Problem / Challenge

The main challenge was building a platform that could realistically represent the flow of accommodation discovery and reservation while also making the experience easy to navigate. We needed to balance a user-friendly interface with functional data handling, ensuring that the project felt like a complete digital product rather than a static mockup.

Our Approach

We approached the project as a full-stack learning experience, combining a frontend experience built with React and supporting data storage and integration with MongoDB and the Tapline API. The goal was to build a practical accommodation platform where users could explore listings and move through the booking journey with minimal friction.

My Contribution / Collaboration

This was a collaboration project, and my contribution involved helping bring together the user experience, frontend structure, and the overall functionality of the platform. We worked as a team to connect the different parts of the application and solve problems as they came up, improving the overall flow and usability of the experience.

Outcome / What I Learned

The project helped me better understand how frontend and backend systems work together in a real application. I gained a stronger understanding of React, database connection flow, API integration, and how collaboration supports problem solving when building complex web experiences. It also reinforced the importance of clean navigation, clear layouts, and user-focused design when creating digital platforms.
