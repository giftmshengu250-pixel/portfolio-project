CASE STUDY

Netflix Clone

A responsive Netflix-inspired landing page created to strengthen my front-end development and responsive design skills.

HTML CSS
View Live Project → Back to Projects

The Problem

I wanted to challenge myself to recreate the visual structure of a familiar streaming platform while developing a stronger understanding of webpage layouts, spacing and responsive design.

My Approach

I broke the page into individual sections and focused on creating a clear visual hierarchy. I used semantic HTML for the structure and CSS to control layouts, spacing, typography and responsive behaviour.

Challenges

One of the biggest challenges was making the layout remain visually consistent across different screen sizes. I had to understand how Flexbox, sizing and responsive CSS techniques could work together rather than designing only for a desktop screen.

The Solution

I created reusable layout patterns and used responsive CSS techniques to allow the page to adapt to different viewport sizes. I also focused on spacing, alignment and visual hierarchy to make the interface feel closer to a real streaming platform.

What I Learned

  • Structuring webpages using semantic HTML
  • Using Flexbox to create responsive layouts
  • Improving spacing and visual hierarchy
  • Designing for different screen sizes
  • Translating an existing design into code
