CASE STUDY

Barber Booking System

A barber shop booking and queue management experience designed to make the booking process simple and convenient.

HTML CSS JavaScript
View Live Project → Back to Projects

The Problem

I wanted to explore how a barber shop could use a simple digital experience to make booking and managing customers more convenient. The goal was to create an interface where customers could view services and join a queue without needing a complicated booking process.

My Approach

I designed the experience around two main actions: allowing customers to view available services and allowing them to join a queue. I used HTML to structure the pages, CSS to create a responsive interface, and JavaScript to handle the booking form and dynamically update the queue.

Challenges

One of the main challenges was understanding how form data could be collected and turned into useful information on the page. I also had to work through DOM manipulation and learn how JavaScript could dynamically create queue cards instead of relying entirely on hard-coded HTML.

The Solution

I created a booking form that collects the customer's name, phone number and selected hairstyle. JavaScript converts this information into an object and stores it in a queue array. The queue is then displayed dynamically using DOM manipulation.

What I Learned

  • Working with JavaScript objects and arrays
  • Handling form submission and user input
  • Using DOM manipulation to create dynamic content
  • Connecting HTML, CSS and JavaScript into one application
  • Designing around a real-world business problem
